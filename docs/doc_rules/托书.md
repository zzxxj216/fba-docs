## MSKU→赛狐SKU 匹配规则(公共规则,商品资料取数用)
依次尝试直到命中:原值 → 去站点后缀(-US/-UK/…) → 去 `-New` → 去尾部数字批次码(`-\d{1,3}`,Zentop:B1S-66DL-016→B1S-66DL) → 每种再试去尾部引号(6")。
已验证:HUHOLE(引号)、Rafter(-US)、Zentop(数字码)三类命名差异全覆盖。
