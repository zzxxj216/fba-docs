## 行为规则
- 投保单 `requires_forwarder_no=True`:缺盈和订舱号时**置空照出+显式提示**(preview 同口径);订舱号回填后重出。
- 货值用合同系数(舟峰/保峰1.695、其余1.0)——与报关加价(1.1/1.5)是两套,不混。
